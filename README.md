# Rust Library Tracker

## Overview
The Rust Library Tracker is a command-line application designed to manage a personal book collection efficiently. It allows users to add new books, list existing entries, toggle checkout statuses, view collection statistics, and persist data locally using JSON files.

## Development Environment
* **Language:** Rust (Edition 2021)
* **Package Manager / Build Tool:** Cargo
* **Dependencies:** 
  * `serde` (v1.0 with "derive" feature)
  * `serde_json` (v1.0)
* **IDE:** Visual Studio Code
